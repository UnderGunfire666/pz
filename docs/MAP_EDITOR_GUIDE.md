# 原生地图编辑器使用说明

## 入口与基本操作

Godot 4.7.2 打开项目，右侧选择 **Map Authoring**。若不可见，在项目设置 → 插件中启用 **Native Map Authoring**。

- **Open demo** 加载示例，**New** 按尺寸框创建全草地地图；先用 **Save as** 保存副本。
- 画布左键拖动编辑；滚轮缩放，中键拖动平移。
- **Active floor** 使用从 0 开始的楼层编号；输入框允许超过显示的默认范围。相邻层只作半透明参考。
- **Select** 单击选一格、拖动框选；点击房屋同时将它设为墙体、楼梯、复制等操作的目标，但不扩大格子选择。
- 操作通过编辑器撤销管理器提交，支持撤销/重做。替换已占内容先确认，取消不改变地图。

## 地形、道路与房屋

**Terrain** 在地面层矩形填充 Grass / Soil / Water。**Road** 是独立笔刷，宽度为整数格；碰到水面截断，不跨岸继续绘制。删除道路显露原地形。房屋、道路、物件占用的地面不能直接改水面；普通地形修改不移除其上道路或室内地面。

用 **Indoor floor** 框出第一层地面，会生成一个房屋实例。选中房屋，切换到上层后在其范围内铺地。首版新增楼层必须位于房屋既有占地范围；要扩大占地，先创建更大的布局，再作为模板保存。墙、门、窗沿整数格边界拖直线；替换墙段需确认。试玩时靠近门窗按 **E** 开关：关闭时阻挡移动、寻路与视线，打开时允许通过；状态写入快速存档。开关只刷新门窗附近的导航和所属渲染分块，避免整图重建造成卡顿。

**Stair** 点击放置直楼梯，按旋转选项朝四个方向上升，长度 3 格，连接当前层与上一层。上下落脚点需已有地面，路径不能穿墙。上层中间两格使用非破坏性开洞遮罩；删楼梯或撤销后恢复原地面及热力。玩家沿坡连续移动，楼层信息用于既有可见性与导航系统，不是传送。

**Toggle selected house roof** 切换独立屋顶。楼板兼作下一层天花板，不维护第二份天花板。

## 房屋模板

框选完整房屋占地，用 **Save template** 保存 `.tres`，捕获所有楼层的地面、墙/门/窗、楼梯、屋顶开关和室内热力。选择模板后进入 **Stamp template**，可连续点击放置；支持 90° 旋转和镜像，绿色/红色占地预览表示边界与水面检查结果。

每次放置独立深复制资源。碰到旧房屋任意部分，会提示整栋替换；撤销恢复完整旧房屋。**Copy house / Move house / Delete house** 操作选中的整栋房屋；移动在目标有效且确认后才移除原位置。不要将多栋具有不同屋顶设置的房屋合并捕获为一个模板：首版模板只有一个屋顶开关。

## 热力与人口

打开 **Heat overlay** 显示蓝 0 → 红 1 的图例。选单格或矩形，设置 Heat 后点 **Apply heat to selection**；同一平面位置的不同楼层独立编辑。0 排除初始生成，1 表示最大相对权重，不保证生成一只。未绘制的可行走地面为 0.1；水变陆地重置为 0.1。楼梯主体、水面和不能站立的位置不参与生成。

室内外候选位置进入同一加权抽样池。模板热力不乘以室外热力，不设置每栋配额。拆屋移除室内热力，原位置地面恢复 0.1。

人口由 `resources/zombie/world_rules.tres` 的 `population_preset` 独立控制：Very Few 1–3、Few 4–6、Normal 7–10、Many 11–16、Very Many 17–24、Extremely Many 25–32。当前默认 Normal；没有新建世界界面。档位与实际初始数量写入存档，死亡不补员。如果有效候选格少于目标数，只生成实际可容纳数量。测试世界采用地图 ID 的确定性随机种子。

示例地图已将旧区域压力迁到地图热力：野外 0.12、道路 0.26、三栋房屋分别 0.22 / 0.82 / 0.34。新地图仍使用 0.1 基础值。`ZombieAreaDefinition` 的原点位、邻接与压力兼容字段仅保留给迁徙；不再决定初始生成位置。没有新增 loot/migration 区域工具。

## 尺寸、保存与试玩

尺寸框 + **Resize** 扩张时补草地；缩小时画布红框预览保留范围，确认窗口列出受影响房屋、道路、物件等。越界房屋整栋移除，地形/热力裁切；撤销恢复。

**Validate** 检查资源结构，**Save** 保存原生地图资源。**Play saved map** 必须成功校验和保存后才启动主场景，并通过 `--map=` 参数传入当前地图；后续普通运行不会永久改用该地图。新地图不注入示例街区的硬编码测试容器，NPC 的临时住所使用地图出生点。

存档仍采用 v8。已核验的原版 Orangeville（提交 c8bcc79）指纹可以迁移到本次热力格式 2；已有僵尸保持存档状态，不重新生成。不对任意改过布局的地图绕过指纹校验。

## 实现边界与后续高优先级工作

- **高优先级：门窗开关/破坏交互、状态保存及正确的寻路与视线阻挡。** 当前静态门窗不作为实心墙。
- 楼层布局和模板可以编辑，但不自动识别由内墙分隔的独立房间；现有建筑可见性按房屋/楼层接入。
- 屋顶目前为占地矩形，不是任意轮廓屋顶编辑器；3D 预览展示完整静态地图，主要编辑视图是分层 2D 画布。
- 首版不是物件/家具/搜刮点编辑器；已有物件参与占用和覆盖检查，物資仍属于容器系统。
- 地图源数据和导航仍是全图加载，渲染继续使用既有分块机制。不要把编辑器支持更大尺寸理解为已验证大型城市性能。
- 自动化覆盖数据操作、资源重载、运行时和撤销核心；可视化拖拽手感、编辑器快捷键路由与真实窗口试玩仍需人工验收。
