# 衣物与手持设备

衣物仍是普通 `ItemStack`：沿用唯一实例 ID、重量、尺寸、容器所有权和硬负重限制。九个穿戴槽属于 `InventoryGrid` 的根容器，因此一件物品不可能同时存在于衣物槽、手部或背包中；穿戴重量完整计入玩家负重。

`ItemDefinition` 保存槽位、覆盖部位、各部位保护/温暖/最大耐久和 Rag 产量；实例字典保存各部位当前耐久。`ClothingSystem` 独立计算十个身体部位的保护与温暖。保护判定成功后按外层 2、内层 1 的比例分配伤害，耗尽层的余额重新分配，无法吸收的部分传给玩家。任何一个覆盖部位归零都会销毁整件衣物，并在脚下生成独立 Rag 实例。

换装和脱衣每一步使用 `CLOTHING_CHANGE_GAME_SECONDS`；替换前会预演完整计划，之后按“旧衣进入 Carried、新衣进入槽位”逐步提交。中断只保留已经完成的步骤。修理固定消耗 60 游戏秒，需要随身 Needle、Thread 和 Rag；仅 Rag 被消耗，指定部位恢复最大耐久的 10%，中断时不产生部分结果。

武器和开关设备继续使用 Left Hand、Right Hand、Two Hands。武器定义只增加攻击类型与伤害，复用原近战冷却、体力、朝向和命中检测；无武器保持推击。开关状态保存在物品实例上，可通过右键菜单或右键准备后左键切换。

温暖只显示和持久化：每个部位为所有覆盖衣物之和，总温暖是十个部位的算术平均值，不封顶，也不影响当前生存数值。

身体部位与穿戴槽不是玩家可选择的物品容器标签。已穿衣物仍由内部根槽维护，并包含在 `All carried` 视图中。按 C 打开的独立角色状态栏按十个身体部位显示现有伤口、保护、保暖和覆盖衣物及其区域耐久。

## 当前视觉原型

`PlayerEquipmentVisual` 是权威衣物槽的纯渲染投影。它按 `InventoryGrid.revision` 刷新，不保存另一份穿戴状态。当前 `jacket` 在 `outer_top` 时，会在玩家的 `TorsoAnchor` 下显示程序化八边形工装夹克、袖子、领口和前襟；脱下、销毁或读档改变槽位后同步隐藏或恢复。玩家基础身体已拆成低多边形躯干与较窄下身，以避免单胶囊穿出夹克。现阶段仅验证 Outer Top，其他八个槽位等待正式模型或下一轮程序化占位件。
